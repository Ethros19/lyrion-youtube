PLUGIN_YOUTUBEDIRECT_MENU
	EN	YouTube Direct

PLUGIN_YOUTUBEDIRECT_DESC
	EN	Play YouTube audio on Lyrion, with SponsorBlock: sponsor reads, self-promotion and the non-music parts of music videos are cut out as you listen. Search, follow channels, browse playlists, open links, and see a mix's chapters as now-playing. Works on Lyrion 8 and 9 (including 9.0 servers that can't upgrade) with no shell access: it installs and updates its own copy of yt-dlp. An API key is optional.

PLUGIN_YOUTUBEDIRECT_API_KEY
	EN	YouTube Data API key (optional)

PLUGIN_YOUTUBEDIRECT_API_KEY_DESC
	EN	Without a key, search and browsing go through yt-dlp, a little slower but with no quota. With a key (free from Google Cloud Console: enable "YouTube Data API v3", then create an API key) they're faster, limited to about 100 searches a day. If the key stops working, the plugin quietly falls back to yt-dlp.
